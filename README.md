# AurenInda Jewellery

Premium minimal jewellery website built with React and designed for GitHub Pages deployment.

## Features

- Premium luxury storefront design
- Minimal white-and-gold visual style
- Product categories with subcategories
- Best sellers and bridal section
- Ratings, reviews, and trust statistics
- Responsive layout for mobile and desktop
- GitHub Pages ready configuration

## Tech Stack

- React
- JavaScript
- CSS
- GitHub Pages

## Local setup

```bash
npm install
npm start
```

## Deploy to GitHub Pages

1. Update `homepage` in `package.json` with your site URL.
2. Run:

```bash
npm run deploy
```

## Custom domain

Update the `CNAME` file with your domain if using a custom domain.
